# Be™ Brooklyn Equine — website

Marketing site for **Be™ Brooklyn Equine at Prospect Park Stable**, Brooklyn's only
centrally located stable. Horse care and riding programs for all ages — pony rides,
trail rides, riding lessons, and after-school/summer programs in and around historic
Prospect Park.

**Live site:** https://REPLACE_WITH_PAGES_URL/

## Stack
Static single-page site — one `index.html` with inline CSS/JS and two photos. No build
step, no dependencies, no framework. Hosted on GitHub Pages.

```
index.html      # the whole site
hero-ride.jpg   # hero background — trail ride in Prospect Park
stables.jpg     # about-section photo — neighborhood pony ride
.nojekyll       # serve files as-is on Pages
```

## Preview locally
Open `index.html` directly in a browser, or serve the folder:

```
python -m http.server 8000    # then visit http://localhost:8000
```
